코스 한 번에 저장

ChatGPT가 보내준 전체 코스 BRC 링크 1개를 붙여넣어. 경유지가 6~10개 이상이어도 BRC가 자동으로 카카오내비용 구간을 나눠줘.

예: 경유·도착 지점 8개 → 1구간 4곳 + 2구간 4곳. 각 구간은 카카오내비에 경유지 최대 3곳과 목적지 1곳을 전달해. 주행 중이 아니라 안전하게 정차한 뒤 다음 구간을 실행해.
링크를 열고 ‘보관함에 저장’을 눌러도 돼. 새 p= 통합 링크와 예전 v= 경유지 링크 모두 최대 60개 지점까지 자동 분할해.
또는 장소와 좌표를 직접 입력 / 이전 구간 링크 사용
출발지는 넣지 말고 처음 경유지부터 마지막 귀가 목적지까지 넣어줘. 장소 이름만으로 좌표를 자동 검색하지는 않아. 주소와 좌표가 반드시 일치해야 해.

라이딩 안전: BRC는 장소 좌표를 카카오내비에 전달하는 도구야. 기존 코스의 실제 도로선, 편의점 진출입, 고속도로·자동차전용도로 제외는 자동 검증하지 못해. 주행 전 반드시 카카오내비의 이륜차 경로 미리보기를 확인해. 주행 중 화면 조작은 하지 마.
