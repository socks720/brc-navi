카카오내비로 열기

전달받은 코스 링크를 열고 버튼만 누르면 카카오내비에 목적지와 경유지를 전달해.

BRC ROUTE LINK · 최대 경유지 3개

코스 정보 확인 중

    카카오맵에서 코스 미리보기

    바이크 주행 주의: 이 페이지는 입력된 좌표를 카카오내비로 넘기는 도구야. 고속도로·자동차전용도로 회피 옵션을 요청하지만, 실제 경로의 통행 가능 여부와 순방향 진출입까지 검증하거나 원래 카카오맵 도로선을 보장하지는 않아. 출발 전 카카오내비 미리보기를 꼭 확인해.

    이륜차 설정(vehicleType 7) · 자동차전용도로 제외(rpOption 4)
    경로를 열면 현재 위치부터 다시 탐색해. 공식 카카오 JavaScript SDK 사용.
